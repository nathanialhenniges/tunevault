Open Settings with <kbd>⌘ ,</kbd> on Mac or <kbd>Ctrl ,</kbd> on Windows.

| Tab          | What's there                                                                              |
| ------------ | ----------------------------------------------------------------------------------------- |
| **General**  | Appearance (System, Light or Dark), accent colour (Blue or Orange), and the welcome guide |
| **Library**  | Library folder, backups and restore                                                       |
| **Sources**  | Online metadata and artwork services, and the optional cookie credentials for links       |
| **Updates**  | Check for updates                                                                         |
| **Privacy**  | What's stored on your computer, your agreements, and the legal documents                  |
| **Advanced** | Bundled tool versions, support report and design fixtures                                 |

Picking the **Orange** accent also switches the app logo to orange.

## About and third-party licenses

Open **About TuneVault** from the app's native menu. About shows TuneVault,
Electron, Chromium, Node.js, SQLite, bundled media tools and direct app-library
versions. **Copy version info** copies those details for troubleshooting.

**About → Third-party notices** opens the bundled license/disclaimer page offline.
The app's MIT license does not relicense FFmpeg, yt-dlp or other components;
each keeps its own license. Privacy, Terms and installation help are available
there too. Never include private paths or credentials in a public issue.
