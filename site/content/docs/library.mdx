## Finding tracks

- **Search:** type in the search box at the top (<kbd>⌘ F</kbd> / <kbd>Ctrl F</kbd>).
- **Filters:** the sidebar has quick filters:
  - **All tracks**
  - **Favorites**
  - **Needs review:** tags that look incomplete
  - **Missing artwork**
  - **Ready for target:** tracks that can go to a player

## Selecting tracks

The track list works like Finder or File Explorer:

| Action | How |
| --- | --- |
| Select one | Click it |
| Select a range | <kbd>Shift</kbd> + click |
| Add or remove one | <kbd>⌘</kbd> / <kbd>Ctrl</kbd> + click |
| Select all | <kbd>⌘ A</kbd> / <kbd>Ctrl A</kbd> |
| Move | Arrow keys (hold <kbd>Shift</kbd> to extend) |
| Open details | Double-click, or press <kbd>Enter</kbd> |
| Clear selection | <kbd>Esc</kbd> |

With tracks selected, a bar appears so you can favorite them, add them to a playlist, and
more.

## Track details

Double-click a track to open **Track details**. You can edit the title, artist, album,
track and disc numbers, and artwork.

- Each field shows **where its value came from**, such as the file's own tags, your edit,
  or a MusicBrainz lookup.
- **Lock** a field to stop lookups from changing it.
- Every save is kept as a revision, so you can **undo** changes.

To fill in missing details automatically, see [Tags and artwork](/docs/metadata).
