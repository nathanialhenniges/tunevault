title: Troubleshooting
description: Fixes for common problems.
---

## The Mac says TuneVault can't be opened

That's expected on first launch. Go to **System Settings → Privacy & Security → Open
Anyway**. See [Install](/docs/install#mac).

## Windows says it protected my PC

Click **More info → Run anyway**. See [Install](/docs/install#windows).

## A track shows "Needs review"

Some of its tags look incomplete. Open it and use **Find suggestions**, or edit the fields
yourself. See [Tags and artwork](/docs/metadata).

## Some songs were skipped in an export

**Review export** lists each skipped song and why, such as a missing file or no compatible
format. Fix those tracks in the library and export again.

## Lookups don't work

Check that online lookups are on in **Settings → Sources**, and that you're connected to
the internet. MusicBrainz and Cover Art Archive are community services and are sometimes
briefly unavailable.

## I need more help

Open an issue on [GitHub](https://github.com/nathanialhenniges/tunevault/issues). Issues
are public, so never post passwords, cookies or private logs. A support report from
**Settings → Advanced** helps.
