## Requirements

| Computer | Requirement |
| --- | --- |
| Mac | Apple Silicon (M1 or newer), macOS 15 or later |
| Windows | 64-bit PC, Windows 10 or 11 |

Intel Macs aren't supported. You don't need anything else installed: the tools TuneVault
uses come bundled with the app.

## Download

Get the latest version from the [GitHub releases page](https://github.com/nathanialhenniges/tunevault/releases):

- **Mac:** `TuneVault-<version>-mac-arm64.dmg`
- **Windows:** `TuneVault-<version>-win-x64.exe`

Only download TuneVault from that page.

## Mac

1. Open the `.dmg` file.
2. Drag **TuneVault** into **Applications**.
3. Open TuneVault from Applications.

TuneVault isn't signed with an Apple Developer ID yet, so the first launch is blocked. To
allow it:

1. Open **System Settings → Privacy & Security**.
2. Scroll down and click **Open Anyway** next to the TuneVault message.
3. Confirm, and TuneVault opens. You only do this once.

<Callout type="warn">
  Don't turn off Gatekeeper or run terminal commands to remove quarantine. Open Anyway only
  allows TuneVault.
</Callout>

## Windows

1. Run the `.exe` installer.
2. If **Windows protected your PC** appears, click **More info → Run anyway**. This shows
   because the installer isn't signed with a Microsoft publisher certificate yet.
3. Follow the installer. It installs for your user account only, and you can choose the
   install folder.

Never turn off your antivirus to install TuneVault.

## Uninstalling

Uninstalling removes the app only. Your library, music, exports and backups stay where
they are.
