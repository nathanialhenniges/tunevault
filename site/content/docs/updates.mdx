---
title: Updates
description: How TuneVault checks for and installs new versions.
---

Check for a new version in **Settings → Updates**. Updates come only from the official
GitHub releases and are signature-checked before anything is installed. If a check fails
verification, nothing is installed.

## Mac

1. TuneVault downloads and verifies the new `.dmg`.
2. Click **Reveal installer**.
3. Quit TuneVault, drag the new version into Applications to replace the old one, and
   reopen it.

## Windows

TuneVault downloads and verifies the installer, then installs it when you click to
install. It never updates by itself while you're using it.

Your library and music aren't touched by updates.
