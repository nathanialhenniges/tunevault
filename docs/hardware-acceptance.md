# Physical acceptance

No physical transfer or playback is established by source, packaged or installer
tests. Use owned or generated synthetic audio, not an unlicensed live fixture.

- [ ] Record iPod touch 6 model, iOS version, iMazing version and host OS.
- [ ] Prepare MP3/AAC/ALAC samples, Unicode tags, artwork and a long mix.
- [ ] Transfer through iMazing and check duplicate handling and playback.
- [ ] Verify seeking, embedded artwork and exact duplicate playlist order.
- [ ] Mark only that checked batch transferred; another target remains pending.
- [ ] For generic USB, record model/firmware and test its actual codecs,
      playlist encoding/order and artwork limits. A verified copy proves bytes,
      not playback. Keep compatibility Baseline until actual tests are recorded.
- [ ] Android/MTP uses folder handoff unless a real native transport is tested.

No video, DRM bypass or private iOS-library manipulation is in scope.
